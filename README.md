# 📋 Sistema de Cadastro de Usuários

## 📖 Sobre o Projeto

O Sistema de Cadastro de Usuários é uma aplicação desenvolvida com o objetivo de realizar o registro e gerenciamento de participantes de forma prática e eficiente. O projeto foi criado utilizando tecnologias web para a interface e Python para o processamento dos dados, com armazenamento das informações em banco de dados relacional.

Além do cadastro tradicional, o sistema conta com uma funcionalidade de geração automática de números identificadores únicos para cada usuário registrado. Esses identificadores podem ser utilizados em sorteios, campanhas promocionais, controle de participantes e processos internos que necessitem de numeração sequencial.

O projeto foi desenvolvido com foco em organização dos dados, facilidade de uso e integração entre frontend, backend e banco de dados.

## ⚙️ Como Funciona

1. O usuário acessa a página de cadastro.
2. Preenche os dados solicitados no formulário.
3. As informações são enviadas para o servidor Python.
4. Os dados são validados e armazenados no banco de dados.
5. O sistema gera automaticamente um identificador único para o registro.
6. Esse identificador pode ser utilizado para controle interno ou participação em sorteios.
